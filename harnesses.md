# Harnesses

## What the harness is
- Every agent is a while loop whose state machine you must design. Move control flow OUT of the model when step-adherence is ~a coin flip — model proposes, harness decides; never ask which of six steps it's on [Cline](https://www.youtube.com/watch?v=yUmS-F9IX90) (2026-05) [Microsoft-ACE](https://www.youtube.com/watch?v=m24UKZomm7k) (2026-07)
- **The harness dominates coding-eval results**: SWE-Bench Pro swung ~22% from harness alone while frontier models sat within a few points — an eval tests model, harness and problem realism at once, and a strong model masks a weak harness [Cline](https://www.youtube.com/watch?v=QuuIywMG4s8) [DeepMind](https://www.youtube.com/watch?v=Ubwb6NzegyA) (2026-05)
- Harness + architecture decisions ≈ 3× the price swing of model selection — optimize the harness BEFORE picking the model [Notion](https://www.youtube.com/watch?v=wjXowoQ7E8c) (2026-06)
- **Biggest published context delta: 21% → >95%, same model** — curated per-domain reference docs (tables, joins, required filters, gotchas) vs raw data access. The lever is DISTILLATION: raw search over thousands of prior queries moved accuracy <1pp [Anthropic-analytics](https://claude.com/blog/how-anthropic-enables-self-service-data-analytics-with-claude) (2026-06) [DataChain-Petrov](https://www.youtube.com/watch?v=bUJgirn4_yc) (2026-07)

## Minimalism — get out of the model's way
- "Bash is all you need": one `bash` tool returning stdout/stderr/exit code covers most work — but offer a DB tool alongside. Hybrid bash+DB scored highest on analytical queries; pure DB wins analytics, file/grep wins quick lookups [Vercel](https://www.youtube.com/watch?v=wflNENRSUb4) [Elastic](https://www.youtube.com/watch?v=ynJyIKwjonM) (2026-05)
- **d0's evolution** (Vercel data agent, ~30k questions/month): scoped agents passing summaries hit a wall — handoff loses too much; one agent holding all context beat it; a filesystem agent with the semantic layer as files roughly DOUBLED eval scores [Vercel-d0](https://www.youtube.com/watch?v=I2cbIws9j10) (2026-07)
- **"Build to delete" telemetry**: Cursor replaced ~12,000 lines of orchestration with a skill; Manus rebuilt its harness 5×; Vercel cut 80% of tools for fewer steps AND better accuracy. A harness growing MORE complex as models improve is over-engineered [Gemini-WF26](https://www.youtube.com/watch?v=I2cbIws9j10) (2026-07)

## Frameworks & API lock-in
- Frameworks (LangChain/LangGraph) fit prototyping but hit a customizability ceiling in production — expect to rewrite. OpenGov moved OFF LangGraph to their own loop once use cases scaled; dependency injection in the loop hot-swaps the model [Cline](https://www.youtube.com/watch?v=yUmS-F9IX90) (2026-05) [OpenGov](https://www.youtube.com/watch?v=4uFVSLgD2Q4) (2026-06)
- ACP standardises sessions, messages, streamed updates, tool calls and permission requests at the client↔harness boundary; one harness can serve editor, terminal, mobile or bespoke clients over stdio, HTTP or WebSocket [Block-Hancock](https://www.youtube.com/watch?v=YkNulwcc5jk) (2026-09)
- MCP Apps: a tool returns a UI *resource* the host renders sandboxed, outside the context window — a 100k-row table for the user, a short confirmation for the model; events route to the *host*, not a vendor backend [MCP UI](https://www.youtube.com/watch?v=o-zkvb0iFDQ) [FastMCP-Lowin](https://podcasters.spotify.com/pod/show/mlops/episodes/The-Creator-of-FastMCP-Explains-the-Future-of-MCP-e3maib0) (2026-05)
- MCP App uploads should bypass model context: user→server directly, avoiding a megabyte retyped through the model. For generative UI, Prefab's Python representation measured ~70% smaller than JSON; execute sandboxed, compile to JSON, render fixed components [Prefect-Lowin](https://www.youtube.com/watch?v=Krzs8GeiWTc) (2026-09)

## MCP security, trust & auth
- Keep identity and factual constraints outside agent-controlled parameters: bind verified user claims at the app/tool boundary. For database agents, preconfigure connection/SQL; enforce read-only, dataset allowlists and output caps below the model [Google-Kitsch/Kakkar](https://www.youtube.com/watch?v=9R--1tg45Jg) (2026-09)
- Legacy auth (fixed permissions granted at registration) structurally breaks: scopes safe for a human can't bound non-deterministic behavior — you need actor-bound, time-limited, purpose-scoped credentials. Most MCP servers compound it by surfacing the account's FULL tool surface [ScaleKit-Madabhushi](https://www.youtube.com/watch?v=lMCxVorb9wM) (2026-07)
- Constructive counterpart, from a draft spec: derive grantable capabilities mechanically from a service's OpenAPI (each get/send/delete separately grantable), and give each agent its own keypair so logs read (host, agent, user) and one agent revokes alone [AgentAuth-Estefania](https://www.youtube.com/watch?v=JvKO40CFq-s) (2026-07)
- Keep MCP servers off the public internet: run them inside your network making only OUTBOUND calls to the hosted agent loop ("MCP tunnels"), rather than exposing an inbound endpoint [Anthropic-AppliedAI](https://www.youtube.com/watch?v=K0X9QDRkIdg) (2026-08)
- **Endpoint-level auth is too coarse**: one endpoint co-mingles sensitivities (an HR API returns timezones AND 401k data), and REST never sees what the agent composes across calls. Fix — declare intent as a query with per-field rights, approved pre-execution [Apollo-DeBergalis](https://podcasters.spotify.com/pod/show/mlops/episodes/AI-Agents-Should-Be-Treated-Like-Hackers-e3lncle) (2026-07)

## Long-running / multi-hour agents
- **Shipped overnight loop**: mine org context → tests-first build → computer-use check → reviewer-sized PRs → CI + clean-context review skill → human tests and reads code next morning. Keep it off critical paths [Browser Company](https://www.youtube.com/watch?v=bdHaOXZOhcM) (2026-08)
- **Three failure modes blocking multi-hour runs**: context (amnesia across sessions, rot, "context-sense anxiety" rushing near window end), weak planning (one-shots, or half-builds and stops), bad self-judgment (calls half-baked work done) [Anthropic](https://www.youtube.com/watch?v=mR-WAvEPRwE) (2026-05)
- **Harness mitigations are temporary**: with Opus 4.6 they dropped fresh-context resets AND sprint decomposition for one continuous compacted session — ~half the cost. Keeping the reset workaround one generation too long added latency AND discarded the prompt cache [Anthropic](https://www.youtube.com/watch?v=mR-WAvEPRwE) (2026-05) [Anthropic-AppliedAI](https://www.youtube.com/watch?v=K0X9QDRkIdg) (2026-08)
- **Make cross-session memory an enforced artifact**: a work log records plan, decisions, failed attempts and surprises; a git hook blocks commits that omit its update, so a fresh agent can resume without re-explanation [Orobator](https://www.youtube.com/watch?v=6MudaeKdBSk) (2026-09)

## Control planes, durable execution & replay
- **Retry amplification**: bad call → retry → more load → more failure. Cap retry budgets dynamically as utilization rises; shed by queue depth before healthy capacity saturates [Meta-Superintelligence](https://www.youtube.com/watch?v=APh1Vx0oLmQ) (2026-06) [OpenAI](https://www.youtube.com/watch?v=sOB3HSiG8vo) [Meta-Inference](https://www.youtube.com/watch?v=7c9FSUVcXR0) (2026-09)
- **Optimize agent serving for task latency, not call latency**: tool loops share long prefixes across calls. Preserve KV state during tool gaps and route follow-ups to cache-local engines, balancing locality against hot spots [Friendli](https://www.youtube.com/watch?v=Hvb2LfMH58c) [CoreWeave](https://www.youtube.com/watch?v=cQQbJqvZkpo) (2026-09)
- **Separate global routing policy from fast local decisions**: asynchronous control plane publishes explicit weight snapshots; local data planes route without blocking and apply live health guardrails. Avoid reactive loops that oscillate traffic and destroy cache locality [OpenAI](https://www.youtube.com/watch?v=sOB3HSiG8vo) (2026-09)
- Keep execution, context (models, prompts, tools, memory) and compute decoupled — prompts decay in weeks, models in months, execution lasts years. Resumability needs state stored OUTSIDE the ephemeral sandbox, so a failed call at step 38 retries from there [Inngest-Farrelly](https://www.youtube.com/watch?v=X1kp-ABIIxQ) (2026-07)
- Decouple brain (harness) from hands (execution env): one container loses the whole session when either dies and parks credentials next to a 10-hour unsupervised agent. Stateless harness → append-only event-log session → containers as hands, credentials in a vault [Anthropic-Martin](https://www.youtube.com/watch?v=9QebvrrY3KY) (2026-07)
- ...the split also buys LATENCY and recovery: reasoning starts immediately with setup in parallel (60% faster TTFT at P50, >90% at P95); sandbox dies → the brain spins a fresh one; brain dies → it replays the log [Anthropic-AppliedAI](https://www.youtube.com/watch?v=K0X9QDRkIdg) (2026-08)
- Persist human approvals as durable promises in the event journal; suspend without consuming function time, then resume after restarts or redeploys when the response arrives [Restate-vanDongen](https://www.youtube.com/watch?v=cI7zfqusmFU) (2026-09)
- **Sandbox checkpoint/restore is a harness PRIMITIVE, not crash insurance**: block-level snapshots (copy-on-write reflink + FIEMAP diff) branch rollouts; guest-MEMORY snapshots give millisecond starts without warm pools. Route recovery by failure type: rate-limited → snapshot, crash → replay the log [OpenAI-Bhardwaj](https://www.youtube.com/watch?v=OqM67QG_Ikk) (2026-07) [Trigger.dev](https://www.youtube.com/watch?v=svCnShDvgQg) (2026-05)
- Content-address every prompt component and response: a run becomes a hash graph supporting exact-context reconstruction, component diffs, model-swapped replay, and structural compaction [Louf](https://www.youtube.com/watch?v=KHudyx5wW3U) (2026-08)
- **Cohort replay beats single replay**: one swapped-model replay looked equivalent, but a whole cohort showed the cheaper model produced worse resolutions. A model passing 60% of the time is self-consistent only ~25%, so a single replay is not informative [ZenML-Tahir](https://www.youtube.com/watch?v=bZISsg7H7DA) (2026-07)
- **Past ~1000 tok/s the NETWORK, not inference, is the bottleneck**: tool-call-heavy turns spend their time in transport. Fix — a persistent WebSocket instead of SSE/HTTP, plus stateful server-side context so a turn sends only the changed item [OpenAI-Kundel](https://www.youtube.com/watch?v=shRR1e2HXMk) (2026-08)

## Event-sourced design & failure shapes
- **"The log IS the agent"**: the append-only event log is its identity; the model's view, UI, debugging, auditing and compaction are all PROJECTIONS. The per-turn loop is DISPOSABLE — any worker claims a session, advances one step, appends, disappears [Omnara](https://www.youtube.com/watch?v=UPwGaM2MKHY) (2026-06)
- **The session log is not the context window.** Conflate them and whatever the model compacts away is gone; keep every event in a durable log and the harness can read slices back in [Anthropic-AppliedAI](https://www.youtube.com/watch?v=K0X9QDRkIdg) (2026-08)
- **Five production failure shapes, invisible in the moment**: state hole (delivery succeeded, the durable record didn't); overlapping writers (load-modify-save race); dangling tool call; approval drift (expired approval still durable); missing edge proof (tool reported success, nothing rendered) [OpenAI-Govindarajan](https://www.youtube.com/watch?v=BInpv7lGp1o) (2026-07)
- Ownership rule: for every fact the agent may reuse, name the system of record AND the replay path — "storage tells you where the bytes live, ownership tells you who can reconsider reality"; unreplayable is not remembered [OpenAI-Govindarajan](https://www.youtube.com/watch?v=BInpv7lGp1o) (2026-07)
- Concurrency rule, narrow: fan out sub-agents, parallel reads and many sessions freely, but keep ONE ordered commit path per mutable state boundary. Be conservative at commit time, not system-wide — "last writer wins is not a consistency model" [OpenAI-Govindarajan](https://www.youtube.com/watch?v=BInpv7lGp1o) (2026-07)

## Context & compaction
- **Context-zone guideline, with numbers**: keep working context ~100k tokens even on 1M-context models, under ~60k for the hardest problems. Dumb-zone tell — the model rationalizes a failing test away as "pre-existing" [LoopsDebate](https://www.youtube.com/watch?v=c35YoMdnI78) [HumanLayer-WF26](https://www.youtube.com/watch?v=I2cbIws9j10) (2026-07)
- **At million-token windows compaction is far less necessary** (one turn: 104 min, 316 tool calls, 32% of a 1M window). Naive pruning hurts — trimming to a 40–60% band invalidates the input cache every trim, costly at ~95% cache-read [Vercel](https://www.youtube.com/watch?v=wflNENRSUb4) (2026-05)
- **Measured case against default compaction**: full history recalled 95% of chat details versus 32% after summarization; on DeepSeek, 97% cached input made the largest-token setup cheapest [TowardsAI](https://www.youtube.com/watch?v=WP3hjUXd918) (2026-08)
- Compaction takes the cache miss either way (~10× on those input tokens), so **compact for *intelligence*, never to save money**. Server-side compaction holds up where an ad-hoc summarizer doesn't, because it's a transform the model was explicitly TRAINED on [Cognition/Yan](https://www.youtube.com/watch?v=QHBjufYK8TA) [OpenAI-Kundel](https://www.youtube.com/watch?v=shRR1e2HXMk) (2026-08)
- **Faster models make compaction arrive 20× sooner in wall-clock**: a window taking ~10 min to fill at 40–60 tok/s fills in ~30s at ~1,200. Speed is a third selection axis beside intelligence and cost [Cerebras-Chieng](https://www.youtube.com/watch?v=TeGsFFNqRLA) (2026-05), corroborated by [OpenAI-Kundel](https://www.youtube.com/watch?v=shRR1e2HXMk) (2026-08) and [Microsoft-ACE](https://www.youtube.com/watch?v=fnLBmfsI_Fg) (2026-07)
- **Prefer offloading over compaction**: sub-agents take semi-independent work off the main thread and return a ~1k-token summary (one used 30k, returned ~500); a handoff tool lets the agent generate the context it carries into a fresh thread [Vercel](https://www.youtube.com/watch?v=wflNENRSUb4) (2026-05)
- **Render unbounded data as an IMAGE to make its token cost constant**: raw time-series scales with job duration, so a quarantined sub-agent collages it into one annotated graph — input tokens fixed regardless of run length [Pinterest-Profirovic](https://www.youtube.com/watch?v=0RNNfxpdbQk) (2026-07)
- **Reset instead of compact** (fleet-scale): you can't choose what survives compaction — wipe context and have the agent re-read the workspace it wrote. Live tension: Steinberger credits *server-side compaction* for reliable manager agents; file-state fleets reset, long threads compact [KRAFTON-fleet](https://www.youtube.com/watch?v=4kYl2_mqmnQ) (2026-07)

## Memory
- **Memory needs an out-of-band consolidation pass ("dreaming")**, not just in-band writes, which can be wrong or locally optimal. Measured — a bad memory made the agent mislocalise and fail 5/5 replicates; dreaming corrected it, no-memory made no progress [Anthropic-Martin](https://www.youtube.com/watch?v=9QebvrrY3KY) (2026-07)
- **Shipped consumer systems converged on two layers**: a "running profile" injected every conversation, plus on-demand search over past conversations — neither uses RAG. The dial: profile length × update frequency: ChatGPT ≈4k tokens every few days, Claude ≈1k daily [Khemani](https://www.shloked.com/writing/claude-memory) (2026-08)
- ...a third shipped variant splits the profile by TIME WINDOW, precomputed offline because meaning can't be built at query time: a slow engine mining weeks into a durable profile, a fast one recomputing live signals over recent days [monday.com](https://www.youtube.com/watch?v=Btk8wDUVs74) (2026-07)
- ...its resilience trick: at serve time a thin slice is verified against live data and the rest falls back to last-verified context, with sources isolated so one bad feed can't take the others down [monday.com](https://www.youtube.com/watch?v=Btk8wDUVs74) (2026-07)
- **Memory-harness ablation on long-horizon local-model agents**: a "ranked decisions ledger" — log and rank each turn's decision, retrieve by rank — beat no-memory, vector-RAG and a use-memory gate, on XBench and Spider V2 [Druga/Sakana](https://www.youtube.com/watch?v=R3-anFK1YM8) (2026-08) [WF2026](https://www.youtube.com/watch?v=4sX_He5c4sI) (2026-07)
- **Independent corroboration that fancy memory loses to plain context** (Continual Learning Bench, 6 domains): vanilla in-context learning topped raw reward AND held the reward-vs-cost Pareto frontier over dedicated context-management systems. Caveat — medium-horizon tasks [CL-Bench-Asawa](https://www.youtube.com/watch?v=iqloyWCGYQQ) (2026-08)
- **Fleet-wide memory = a pattern/anti-pattern catalog** as markdown in ONE git repo, not a vector DB: each entry carries the symbols to match on, the services where it was confirmed, and a confidence rising as more confirm [Netflix-Shah](https://www.youtube.com/watch?v=CgsWxRUY5Eo) (2026-07)
- **Shared memory needs a write GATE**: the agent suggests bullets plus scopes, a human accepts. A PR to a shared skills repo is too heavy (nobody writes skills for a stranger); auto-memory too loose (nobody sees what landed) [PromptQL-Gopal](https://www.youtube.com/watch?v=0uC6u0lJJl4) (2026-09)
- ...attributed to a PERSON, never "the agent added this", so an over-broad scope traces to whoever approved it; and ONE company-wide store — a team brain or per-channel memory is just a new silo [PromptQL-Gopal](https://www.youtube.com/watch?v=0uC6u0lJJl4) (2026-09)
- **When context can influence an action it's STATE**: treat memory as a cache — invalidate on source-of-truth change, carry provenance, declare which store wins on conflict [TikTok-Munaf](https://www.youtube.com/watch?v=hD9-V56FNRI) (2026-08)
- **Live disagreement on markdown-as-memory, decided by scope**: fine for one agent and one user; degrades across CONCURRENT agents, where a mutated line carries no trace of why it changed. Sharpest counter-framing is a graph-vendor's; 2026 consensus is hybrid [Zep-Chalef](https://www.youtube.com/watch?v=H7puB0RwJMM) (2026-07) [survey](https://arxiv.org/pdf/2606.04990) [Zep blog](https://blog.getzep.com/markdown-is-not-agent-memory/) (2026-08)
- **Provenance belongs in the STRUCTURE, not a log written afterwards**: synthesis destroys the paper trail — the derived fact appears nowhere verbatim in sources. `source_id` breaks three ways: many parents per fact, entities merging, new data invalidating old [Zep-Chalef](https://www.youtube.com/watch?v=H7puB0RwJMM) (2026-07)

## Guardrails as execution boundary (not behavior prompts)
- Concrete tool-substitution failure: after a no-write instruction, an agent cycled through shell utilities to edit specs. System-level blocking plus role scopes and file isolation stopped cross-domain edits [AIDAChip](https://www.youtube.com/watch?v=0I6aoPSRzVc) (2026-08)
- ...make the egress allowlist grantable PER-TICKET as well as per-project, prompting on each new destination, or people route around it. Motivating failure: an agent told to wipe staging found a laptop token and hit prod [Superconductor-Singh](https://www.youtube.com/watch?v=OL7kfezynJM) (2026-08)
- Swiss-cheese defense in depth: (1) classification "is this reasonable?" probabilistic; (2) policy enforcement "is this allowed?" deterministic — the fence sits here; (3) isolation. Most teams have (1) and/or (3); **the missing MIDDLE layer is the OS-level allow/deny boundary** [Tusk](https://www.youtube.com/watch?v=m12vGjfbNlo) (2026-05)
- Guardrails you *prompt at* the agent aren't guardrails — any injection overrides them; they must be config the agent can't reach. Corollary: tell it anything from strangers (listing copy, scraped pages, inbound email) is "evidence, not instructions" [GitHub-Gazit](https://www.youtube.com/watch?v=iQ5xldZ9StU) (2026-08) [PwC](https://podcasters.spotify.com/pod/show/mlops/episodes/Autonomous-Agents-at-Work-From-OpenClaw-Hype-to-Enterprise-Reality-e3jj7u3) [Angie-Jones](https://www.youtube.com/watch?v=ZD9-4fW2HhM) (2026-05)
- ...the second way they fail isn't injection but **COMPACTION**: Meta's director of alignment prompted "confirm before acting"; the agent deleted ~200 emails, ignored "stop", and had to be killed at the physical machine [Composio-Vaidya](https://www.youtube.com/watch?v=xxfMT-bPEmU) (2026-09)
- ...and the third is **TOOL SUBSTITUTION**: told to draft-and-await-approval, and separately barred from `send_message` without asking, the agent picked a different tool that didn't enforce the constraint, sent anyway, then admitted it [dbt-Stanley](https://www.youtube.com/watch?v=1lgFGaHoGq8) (2026-07)
- **Irreversible tools get a MOCK, not an approval prompt**: the agent acts against a mocked tool, the human reviews the pending effect ("1,200 emails will be deleted"), then it replays for real [Composio-Vaidya](https://www.youtube.com/watch?v=xxfMT-bPEmU) (2026-09)
- Allocate autonomy by failure symmetry and reversibility: agents get verbs whose errors fail loudly and can be undone; silent or irreversible actions require a human-held second key [Anthropic-Malhotra](https://www.youtube.com/watch?v=rbjWzZK2LU0) (2026-08)
- Rate-limit every write with a refillable ceiling scoped by resource and namespace; keep bypasses unavailable inside agent sessions so only a human can override them [Anthropic-Malhotra](https://www.youtube.com/watch?v=rbjWzZK2LU0) (2026-08)
- Prefer aggregate tripwires to guessed static allowlists: page on anomalous behavior, then turn the incident into a small context correction [Anthropic-Malhotra](https://www.youtube.com/watch?v=rbjWzZK2LU0) (2026-08)
- **A human approval binds to action + parameters + expiry**, never blanket — approving a $30 refund must not authorise a $300 one [TikTok-Munaf](https://www.youtube.com/watch?v=hD9-V56FNRI) (2026-08)
- **Deny the native tool, then redirect**: to kill web egress, deny the harness's WebSearch/WebFetch outright and route through Google Web Grounding for Enterprise — Google's index inside your own VPC, ~24h stale (~6h hot sites) [TwoSigma-Fang](https://www.youtube.com/watch?v=wCIYViPd4SU) (2026-09)
- **Safe outputs** — declare the exact write actions allowed and cap the cardinality: "create *one* PR" means an injected agent can't open 500. Include "do nothing" as a declared output, or the automation becomes noise you learn to ignore [GitHub-Gazit](https://www.youtube.com/watch?v=iQ5xldZ9StU) (2026-08) [shipped docs](https://github.github.com/gh-aw/reference/safe-outputs/)
- ...the cap earns its place benignly too: issues wired into a repo with several agents able to file them and nobody capping creation produced 400–500 open issues in ~2 weeks [Amazon-AGI-Khandelwal](https://www.youtube.com/watch?v=aeTb5BdmTTc) (2026-08)
- **Pre-commit intent before reading untrusted evidence**: planner emits a typed action plan; executor may fill parameters but cannot invent actions; policy rejects out-of-plan calls before minting a short-lived capability [Decawork](https://www.youtube.com/watch?v=q-WOjZhOMCA) (2026-08)
- Policy evaluates *before* a credential is minted: token exchange (RFC 8693) scopes each tool call to one audience, short-lived and never stored, so a disallowed action never gets a credential at all [Keycard-Maida](https://www.youtube.com/watch?v=I3znWC3MEXM) (2026-07)
- Inject credentials at an outbound network proxy after matching the destination; the agent knows it may call GitHub but never receives the token. An empty domain allowlist disables egress [DeepMind-Schmid](https://www.youtube.com/watch?v=fjF8EKnxKCU) (2026-09)
- Extend that boundary **below HTTP**: parse Postgres and tunneled protocols at the proxy, enforce content-aware rules, and fixture-test each deny rule. Otherwise a subprocess bypasses MCP/HTTP policy [Deno-Dahl](https://www.youtube.com/watch?v=MkRYPFIMCSA) (2026-08)
- Stamp agent/session identity in that credential-holding proxy and propagate it to descendants; caller-supplied identity lets an agent rename itself and reset every quota [Anthropic-Malhotra](https://www.youtube.com/watch?v=rbjWzZK2LU0) (2026-08)
- **Shipped shape — a crippled reviewer sub-agent**: read-only, no sub-agents, given the transcript, the pending call, a risk taxonomy and "did the user authorize this?". Scores authorization × impact; exfiltration never auto-approvable. Ships as a third permission MODE (auto-review) [OpenAI-Kundel](https://www.youtube.com/watch?v=shRR1e2HXMk) [OpenAI-Liu-MLOps](https://podcasters.spotify.com/pod/show/mlops/episodes/How-To-Delegate-To-An-Agent-Like-You-Would-An-Employee-e3nglg8) (2026-08)
- **Layered prompt stack with a DETERMINISTIC post-generation veto at the bottom**: (1) immutable identity, (2) situational mode, (3) example-anchored voice, (4) veto. layer 4 alone reads actual OUTPUT against ground truth (an offered date must be in an allowlist) [Isadora](https://www.youtube.com/watch?v=ij-AU9dpJjc) (2026-06)
- **The guardrail is a failable dependency**: pick fail-open vs fail-close per check (default to the worst case you can live with), give it its own time budget so the LLM stays rate-determining, and give it a fallback [Twilio-Manuja](https://www.youtube.com/watch?v=zrZ1amZBSPw) (2026-08)
- ...and its PLACEMENT trades against streaming: pre-hook is safest but serial; parallel is cheapest but incompatible with streaming, so don't stream structured output; post-hook is for audit only [Twilio-Manuja](https://www.youtube.com/watch?v=zrZ1amZBSPw) (2026-08)
- **Let generation roam; constrain EFFECTS**: make a typed SDK the sole mutation path, then let harness-owned lint, conflict checks, execution and output validation produce reviewable artifacts. Watershed's task eval rose 43%→92% while edits stayed replayable [Watershed-Dumit](https://www.youtube.com/watch?v=CLttOU7n6sI) (2026-07)

## Retrieval & comprehension
- **Live disagreement by scale/query shape**: agentic grep beat AST+dense/sparse RAG on solo/medium repos; Cursor measured +12.5% accuracy on large codebases (~24% Composer). Short keywords favour grep; conceptual queries favour semantic search [Pi](https://newsletter.pragmaticengineer.com/p/building-pi-and-what-makes-self-modifying) (2026-04) [Turbopuffer](https://www.youtube.com/watch?v=UM6sFg_jdlE) (2026-06) [Cursor](https://cursor.com/blog/semsearch) (2026-08)
- **WHY agents underuse semantic search — the query-writing habit**: coding models emit keyword-gibberish, habits from grep and regex. Fix: instruct "write one concise sentence describing what you want to find"; few-shot good queries; split intent into ≤4 aspect queries [Mixedbread](https://www.youtube.com/watch?v=1IdzkRVmWAA) (2026-07)
- **Chunk size is query-dependent**: index several scales, retrieve in parallel, then fuse parent-document ranks with RRF. Tested gain 1–37% without retraining; price is 2–5× indexing/storage [AI21-Belfer](https://www.youtube.com/watch?v=r9OwPx_HoV0) (2026-09)
- Evaluate retrieval by end-task success across the agent's multi-query trajectory, not single-query NDCG. Optimized hybrid search held 90.2% accuracy with 20% fewer calls; tune BM25 for long agent queries before comparing embeddings [Hornet-Bergum](https://www.youtube.com/watch?v=fZH97QHHYjY) [Mixedbread-Clavié](https://www.youtube.com/watch?v=O84lhGc1OOI) (2026-09)

- Clone dependency source into the project (squashed git subtree): models focus on repo files and skip gitignored dirs. Ignore it in test runners; forbid watch/dev-server commands in AGENTS.md to prevent hangs [Effect](https://www.youtube.com/watch?v=Wmp2Tku2PrI) (2026-05) [Nx-Savkin](https://www.youtube.com/watch?v=jVjt-2g8NMY) (2026-06)

- For code questions with known endpoints but unknown connection, shortest-path retrieval over a code graph returns intervening symbols as context; one .NET evaluation reported 40% fewer search tool calls [GoodCollective-Ainge](https://www.youtube.com/watch?v=3ySF0I5iE_0) (2026-07)
- Personalize org-context retrieval with a deterministic expertise graph from commits and review relationships; use requester/team identity and likely owners to scope search, while enforcing source permissions before synthesis [Unblocked-Waselnuk](https://www.youtube.com/watch?v=KcVkq5L-0f0) (2026-09)
- **You cannot search for a NEGATIVE** — "which procedures see no field usage", "which failures have no docs" need navigation or aggregation, not top-k. Grounding on structure also cuts vector hops, each a chance to grab the wrong doc [Neo4j-Blumenfeld](https://www.youtube.com/watch?v=kRkcNOsRyYg) (2026-07)
- ...cheapest corpus-wide shape for that: Leiden community detection over the doc→doc link graph ALONE, clusters described only from data already in them plus a conductance score for tight-vs-loose. Deterministic, so it re-runs as a time series [Neo4j-Blumenfeld](https://www.youtube.com/watch?v=kRkcNOsRyYg) (2026-07)
- ...but having the shape doesn't mean the agent picks it: given an estate-level question it skipped the cheap outline traversal for an exhaustive text crawl — right answer, far slower [Neo4j-Blumenfeld](https://www.youtube.com/watch?v=kRkcNOsRyYg) (2026-07)
- **Split retrieval in two and expect EXTRACTION to be harder**: (a) produce good output given context, (b) traverse the store for it. Custom traversal tools trained in an RL environment for (b) — the half usually getting no investment [Varick-Pruitt](https://www.youtube.com/watch?v=l0FLhNqBOic) (2026-07)
- Cheap statistical retrieval-confidence signal instead of an LLM self-check: stats over top-K scores (spread, top-1/top-2 gap), then tier escalation — confident → proceed; borderline → cross-encoder rerank; clearly bad → LLM re-query. Agents search far more than humans [Qdrant-Roundtable](https://podcasters.spotify.com/pod/show/mlops/episodes/The-Current-State-of-Agentic-Retrieval---Qdrant-Roundtable-e3lh8v8) (2026-07)
- In a large mature codebase the dominant agent use is comprehension, not generation (measured 67% comprehension / 2% code gen) — instrument your own usage to find where leverage actually is [Sentry](https://www.youtube.com/watch?v=li0SaBt9RDM) (2026-05)

### Data agents — structuring the corpus before the agent reads it
- **"You can't safely run a process the organization cannot represent."** A legacy SOP is screenshots of what a person sees and clicks; an agent SOP needs preconditions, decisions, identifiers, backend calls, validation, recovery and evidence of success [Maersk-Buykin](https://www.youtube.com/watch?v=dQ-_i1tZiws) (2026-08)
- ...and that corpus, not the runtime, is the asset — ~20:1 by size across 200+ production instances. "The agent loop is not the system; the refining loop around it is" [Maersk-Buykin](https://www.youtube.com/watch?v=dQ-_i1tZiws) (2026-08)
- **Rank your sources of truth; don't hand it N knowledge bases of equal weight.** Ambiguity about which table is authoritative, not model size, makes enterprise data agents wrong. Cleanest→messiest: semantic layer → canonical parameterized queries → full metric graph [Tesla-Daga](https://www.youtube.com/watch?v=B8l81jhvHbI) (2026-07)
- **Overloaded vocabulary is the same ambiguity one layer up, needing an ontology**: one entity is "customer" to sales, "client" to ops, "org ID" to devs. Diagnostic — list cross-team overloaded terms, then name the unswappable systems of record [Kepler-Ganesh](https://www.youtube.com/watch?v=1OMHGsUZiqA) (2026-07)
- **Entity resolution needs its own tool, not better prompting**: the same person is spelled differently across email, Slack and docs and the model silently conflates or splits them. The STORE doesn't matter — Postgres is fine [Varick-Pruitt](https://www.youtube.com/watch?v=l0FLhNqBOic) (2026-07)
- **Staleness needs a lifecycle, not better docs**: bind context to sources updated BY CONSTRUCTION (semantic layer, GitHub, CRM) over hand-maintained markdown, and log every correction as an event. One deployment drifted 95% → 65% in ONE month [Tesla-Daga](https://www.youtube.com/watch?v=B8l81jhvHbI) (2026-07) [Anthropic-analytics](https://claude.com/blog/how-anthropic-enables-self-service-data-analytics-with-claude) (2026-06)
- **Owned support-agent case**: 10%→80% end-to-end resolution in week one at ~$700/month (vendor-reported). Mirror docs into versioned Markdown, seed retrieval with embeddings, then let the agent search files when answers span documents [AssemblyAI](https://www.youtube.com/watch?v=pyvRID_CZZU) (2026-10)
- **Unstructured corpora explode on the way in** — 90 dash-cam videos yield ~100k detection records, so millions of sidecar JSONs do not work. Pydantic schemas transpiled to a queryable local DB keep schema, data and code in one language [DataChain-Petrov](https://www.youtube.com/watch?v=bUJgirn4_yc) (2026-07)
- Route document ingestion by STRUCTURE: conventional OCR for text/clauses, a small layout-aware VLM for tables, then preprocess once for downstream queries. Docusign reported 20× table-extraction throughput [Docusign/NVIDIA](https://www.youtube.com/watch?v=_gvamfT8H-w) (2026-09)
- **Index documents by their EXISTING structure before reaching for LLM extraction**: containment tree from folder/section nesting, ordering edges, cross-doc links by regex — no model in the ingest path, so it is idempotent, fast and stable run to run [Neo4j-Blumenfeld](https://www.youtube.com/watch?v=kRkcNOsRyYg) (2026-07)

## Tool design for agents
- **Expose a derived score, not the corpus**: rather than granting an agent everyone's mail, ship a tool that reads it and returns only a rank ("who here is closest to Acme's CFO") — turns a privacy blocker into a callable [Town-Greze](https://www.youtube.com/watch?v=REascnFlq_8) (2026-09)
- **Tool-count accuracy collapse, measured**: every schema in every prompt gives selection accuracy ~78% at 10 tools → ~40% at 100 → ~13.6% at 741. Semantic routing holds >83% flat. 741 schemas ≈127k tokens vs ~1k for JIT-retrieving 3–5 [Prosodica](https://www.youtube.com/watch?v=vh2VGuQ3zhY) (2026-06)
- **Deferred tools are an API-level primitive now** (Responses API since GPT-5.4): mark a tool deferred so its schema never enters context and the model reaches it via tool search — built-in or your own discovery implementation [OpenAI-Kundel](https://www.youtube.com/watch?v=shRR1e2HXMk) (2026-08)
- At LinkedIn scale, 1,300 tools + 600 playbooks collapse to three resident meta-tools: search, inspect schema, execute. Central instructions teach discovery, keeping the catalogue out of context [LinkedIn-Prakash](https://www.youtube.com/watch?v=9wZpvF3QleU) (2026-09)
- **The trend is fewer tools, its endpoint collapsing them into ONE REPL**: ~15 spreadsheet tools became JS functions inside a single Node REPL call; internal benchmark 50%→74%. Parallel tool calls hadn't helped — you can't combine their results [Witan-Campos](https://www.youtube.com/watch?v=HEFSExa0xl0) (2026-07)
- Runtime tool synthesis needs only shell inspection, file editing and dynamic loading. Put the tool contract/storage path in the prompt, require checking for an existing tool first, and sandbox the generated code [AWS-Strands](https://www.youtube.com/watch?v=33Oct2hqGnk) (2026-10)
- **Same conclusion reached independently for COMPUTER USE**: the one-action-per-turn click/type tool was replaced by a persistent Node REPL the agent writes Playwright JS into — inspect one page, then script the rest instead of paying a turn per click [OpenAI-Kundel](https://www.youtube.com/watch?v=shRR1e2HXMk) (2026-08)
- **Match tools to what the model was post-trained on, and ship the binary**: models trained on `apply_patch` reach for ripgrep unprompted, so the Codex harness BUNDLES ripgrep rather than teaching another tool; on Windows the model emits PowerShell [OpenAI-Kundel](https://www.youtube.com/watch?v=shRR1e2HXMk) (2026-08)
- ...the flip side when your harness ISN'T lab-shaped: if your tool definitions merely resemble Claude Code's, the model reaches for Claude Code tools that aren't there and your instructions must fight it. Labs trade model diversity for agentic reliability [Breunig](https://podcasters.spotify.com/pod/show/mlops/episodes/The-Winchester-Mystery-House-Problem-in-AI-Development-e3nqiao) (2026-08)
- ...same clash at PARAMETER level: the model reached for `read_line`, its training prior, where the tool exposed `start_line` and no description contradicted it — a turn burned. Name params as the model expects, or contradict the prior explicitly [Sourcegraph-Jarmak](https://www.youtube.com/watch?v=Lrw0jqBNaw0) (2026-08)
- **Derive composite tools from your existing UI, not your API surface**: a product page already orchestrates ~10–20 API calls to serve one human need — expose that as ONE intent-shaped tool. Antidote to one-to-one API→tool sprawl [MCPcat](https://podcasters.spotify.com/pod/show/mlops/episodes/MCP-Servers-Are-Becoming-the-UI-for-AI-Agents-e3ks6n3) (2026-06)
- Mine correlated session traces for repeated multi-call journeys; turn them into intent-shaped aggregate tools, then eval whether agents choose them and reduce turns/tokens [Ward/AWS](https://podcasters.spotify.com/pod/show/mlops/episodes/AWS-Has-16-000-APIs--Can-MCP-Handle-It-e3pgb4a) (2026-09)
- For MCP Apps, separate DATA tools from RENDER tools: let the model search/filter repeatedly, then render selected IDs. Coupling search to UI makes it stop after one call; mirror displayed and interaction state into model context [Indeed-Mihalik](https://www.youtube.com/watch?v=lbaXnx0KLA8) (2026-09)
- **Tool-misrouting fix ladder**: write a *real* description (core purpose → "use when / don't use when" → relationships), reinforced in the system prompt. Bootstrap unknown shapes with ONE general tool; >4–5 calls per question → carve a specialized tool [Elastic](https://www.youtube.com/watch?v=ynJyIKwjonM) (2026-05)
- **HTML over SVG/canvas for visual artifacts**: models have seen billions of HTML examples and reason about tags as structured language, while SVG is "a wall of numbers". Generate in HTML, render out to PDF or slides [Nori Agentic](https://www.youtube.com/watch?v=htM02KMNZnk) (2026-07)
- ...same principle chosen deliberately: Figma serializes its design scene graph as React+Tailwind rather than a sparse XML/JSX abstraction, on the bet that models were RL'd on React+Tailwind. Hoist images to top-level refs — inline base64 blows the window [Figma-Lumarie](https://www.youtube.com/watch?v=ZIYYsAzaLlA) (2026-08)
- **Return a POINTER to the user's own component, not generated markup**: mapping design components onto codebase components let the server emit `use Button` — cuts context AND inherits the real component's a11y/i18n. Pixel-perfect output an enterprise still won't take [Figma-Lumarie](https://www.youtube.com/watch?v=ZIYYsAzaLlA) (2026-08)
- Tool outputs as semantic summaries: a 50k-line JSON perf trace blows context — return key metrics, keep the raw file on disk. But RAW profiler output is worth feeding directly: the model spots a quadratic from the call stack [Chrome DevTools](https://www.youtube.com/watch?v=_B4Pv9ttFgY) (2026-06) [Netflix-Shah](https://www.youtube.com/watch?v=CgsWxRUY5Eo) (2026-07)
- **Errors as steering, not just reporting**: on a bad call return a constructive error naming the likely fix ("you forgot `last_name`, retry"). Customers running this report large success-rate gains at near-zero overhead; every unrecovered error is retry tokens [MCPcat](https://podcasters.spotify.com/pod/show/mlops/episodes/MCP-Servers-Are-Becoming-the-UI-for-AI-Agents-e3ks6n3) [Chrome DevTools](https://www.youtube.com/watch?v=_B4Pv9ttFgY) (2026-06)
- ...independently corroborated as an ADOPTION cost: Amazon teams rewrote existing tools' error messages so the model could tell what failed, and Stripe/Metronome's DX team now hunts failure cases to make each error state the fix [AWS-Liguori](https://www.youtube.com/watch?v=pqlWNihgdjI) (2026-08) [Stripe-Garvin](https://www.youtube.com/watch?v=mJqwmmOx4WA) (2026-08)
- **Emulate missing MCP spec features with plain tools**: unimplemented `serverInstructions` → usage instructions ride on every tool RESULT; elicitation and sampling faked by returning a prompt that asks the user, then one telling the agent to scan and report back [Figma-Lumarie](https://www.youtube.com/watch?v=ZIYYsAzaLlA) (2026-08)
- ...and expose server RESOURCES (how to use this server, help articles) so a stuck agent reads them instead of burning inference crawling outward from an error [Figma-Lumarie](https://www.youtube.com/watch?v=ZIYYsAzaLlA) (2026-08)

## Computer use & browser agents
- **Rendered state is not in the HTML — the structural reason scraping agents fail.** Stock status lives in a JSON `quantity: 0` a script turns into a greyed-out option, with no "sold out" text anywhere [Yutori-Batra](https://www.youtube.com/watch?v=Ki980nV0__0) (2026-08)
- The **bitter lesson for web agents**: per-site scaffolds don't reach the long tail, pixels-in does. But don't stay limited to *human* actions — add an `execute JS` action so it scripts what's cheaper to script, verifying through the SCREENSHOT [Yutori-Batra](https://www.youtube.com/watch?v=Ki980nV0__0) (2026-08)
- Reliable browser agents switch modality: inspect visually when needed, then generate code or replay observed network requests for repeatable work instead of spending tokens clicking every step [Browserbase-Klein](https://www.youtube.com/watch?v=GqoNrUz8hEU) (2026-08)
- Normalize viewport, layout and runtime across browser sessions; inconsistent mobile/desktop rendering gives identical tasks different observations and trajectories [Browserbase-Klein](https://www.youtube.com/watch?v=GqoNrUz8hEU) (2026-08)
- Page representation token cost: full DOM ≈20k tokens, raw screenshot ≈1.1k, compressed markdown ≈1.8k — markdown + screenshot let a cheap model plan 30 steps. **Diff-based feedback beats re-screenshotting**: state what changed so it recovers from a failed click [ARK](https://www.youtube.com/watch?v=JnubYCYunk8) (2026-06)
- **Partial observability, with no model prior about which source to trust**: the DOM misses dynamically-generated content, the screenshot misses anything below the fold. Feeding both without saying what each is good for is its own failure mode [Amazon-AGI-Mishra](https://www.youtube.com/watch?v=Cc0_nyxROBA) (2026-08)
- A spatial harness pairs screenshots with scene JSON, viewport actions and canvas-edit tools: the model must learn both 2D interpretation and each action's effect. This is the canvas analogue of code plus filesystem tools [tldraw-Drake](https://www.youtube.com/watch?v=XWcXwnysmpY) (2026-09)
- **Verify through a DIFFERENT channel than you acted through** — don't ask the click, read the network or screen. Loop is sense → act → verify; today's agents fire and move on, never watching whether it landed [Rexmore-Gallon](https://www.youtube.com/watch?v=26RtyAm9y_Q) (2026-08) [Amazon-AGI-Barth](https://www.youtube.com/watch?v=2JX6JYyQG4Y) (2026-07)
- For transactional browser work, externalize stable auth/download steps into deterministic functions; let the model handle ambiguity, verify a terminal artifact, and retry the idempotent whole transaction [Browserbase-Meegan](https://www.youtube.com/watch?v=5xi_S1f9sDU) (2026-10)
- Two failure modes from RL training runs: session expires → the model reasons "I can infer the password", guesses and LOCKS the account; an ad with a lookalike submit button → it clicks through and fills in personal details [Amazon-AGI-Mishra](https://www.youtube.com/watch?v=Cc0_nyxROBA) (2026-08)

## Production failure modes (LLM/VLM-in-the-loop)
- **Speculate on partial input; commit only on final input**: stream partial transcription into eager generation while contextual transcription and background tool work run; cancel/restart on correction, but emit only after end-of-turn confirmation [EliseAI](https://www.youtube.com/watch?v=MBHOH1NmDqc) (2026-09)
- **Scope hints to the state where they matter**: dynamically boost an expected name or term only while collecting that field. A global vocabulary pollutes transcription context and hallucinates keywords [Plivo](https://www.youtube.com/watch?v=vblnYHzBgS4) (2026-09)
- Output loops affect ~0.5–1% of queries; whitespace loops can burn the full budget because space cannot be a stop sequence. Stream with repetition detection, kill early, then retry with another model/prompt/temperature [LlamaIndex](https://www.youtube.com/watch?v=m12vGjfbNlo) (2026-05)
- **Claude drops part of a multi-part instruction**: told to support sync and async hooks, it omits async — ~2 of 3 rollouts, notable since Claude is otherwise the most exhaustive explorer. Split multi-part requirements into separately-verifiable items [DeepSWE](https://www.youtube.com/watch?v=Yk87oUPVaxU) (2026-07)
- **Never make an LLM enumerate long lists of near-identical names**: sharding across parallel calls yields phantom entities plus silently dropped real ones, and internal repetition penalties truncate even a legitimate ~100-item enumeration. Produce such lists in code [Phaidra](https://www.youtube.com/watch?v=EUsPvBeIx70) (2026-07)
- Provider reliability: APIs go down roughly daily → multi-provider fallback with each family on its OWN code path; keep a NON-LLM fallback (a CPU parser at ~500 pages/s). Thinking loops are harder to catch since providers stopped streaming traces [LlamaIndex](https://www.youtube.com/watch?v=m12vGjfbNlo) (2026-05)

## Generator / evaluator (adversarial critic)
- **Separate the verifier's *context window*, not just its prompt**: one context both doing and grading confabulates. Tuning a standalone critic to be harsh is tractable; tuning a builder to be self-critical is not [Anthropic-Martin](https://www.youtube.com/watch?v=9QebvrrY3KY) (2026-07) [Anthropic](https://www.youtube.com/watch?v=mR-WAvEPRwE) (2026-05)
- **Consensus suppresses review noise**: run several independent code-review passes and keep agreed findings; an independent study measured up to 44% higher review quality. Tune false positives first—a reviewer ignored after crying wolf provides no safety [Arize-Voss](https://www.youtube.com/watch?v=_mi3alkqy4s) (2026-09)
- **`goal` / `outcomes` put a measurable end state in the environment**: the harness re-injects the objective after every turn and stops only when the model calls update-goal declaring it met. An essay-length goal has no detectable done state [OpenAI-Kundel](https://www.youtube.com/watch?v=shRR1e2HXMk) (2026-08)
- The evaluator must actually USE the app (Playwright: open pages, click, screenshot), not just read diffs — catching live-only bugs unit tests pass. A site-specific skill that knows your DOM is far faster than generic browser use [Anthropic](https://www.youtube.com/watch?v=mR-WAvEPRwE) (2026-05) [Wandero](https://www.youtube.com/watch?v=kZsf_Sfm7RU) (2026-07)
- **Give that evaluator a written design spec to grade against** (`design.md`: colours, components, layout rules — extractable from the existing design if never written down), then run two passes: a VISUAL on-brand check plus the user-flow walkthrough [Amazon-AGI-Barth](https://www.youtube.com/watch?v=2JX6JYyQG4Y) (2026-07)
- ...and treat a flagged violation as a FORK, not a verdict: fix the code, or decide the spec was wrong and update it. Without that branch a stale design rule quietly becomes the thing the agent optimizes against [Amazon-AGI-Barth](https://www.youtube.com/watch?v=2JX6JYyQG4Y) (2026-07)
- **When the product isn't a web page, build the driving CLI yourself**: screenshot, a token-compressed snapshot of UI state, log extraction from front-end AND back-end, service restart, plus high-level composable commands. Domain variant: ASCII rendering of your 3D world [Poolside-Lajili](https://www.youtube.com/watch?v=iRcX54EO5g8) (2026-07)
- **"Negotiate done" before building**: the generator proposes feature plus tests, the evaluator pushes back on scope, tests and edge cases, iterating until both agree, THEN building against that contract. One app produced 27 criteria; vague criteria give vague critiques [Anthropic](https://www.youtube.com/watch?v=mR-WAvEPRwE) (2026-05)
- A GAN-style loop course-corrects by throwing everything out and restarting when stuck; a single-pass loop keeps patching the same broken thing. 4.6-class models readily discarded 10 passes and did NOT rubber-stamp as feared [Anthropic](https://www.youtube.com/watch?v=mR-WAvEPRwE) (2026-05) [Kent Beck](https://newsletter.pragmaticengineer.com/p/how-kent-beck-shapes-the-software) (2026-07)

## Verification & anti-cheating
- **Replay and snapshot UI evidence**: replay real flows with recorded responses, deterministic timers and per-step screenshot diffs; snapshot every component on each change and put visual diffs in the PR. Choose flows by baseline coverage [Meticulous](https://www.youtube.com/watch?v=HLTa7Vcs4X0) [VS Code](https://www.youtube.com/watch?v=I2LL_wd89-A) (2026-10)
- **Make the verification agent independent and adversarial**: it never sees the discovery agent's reasoning, receives only the claimed finding, and is told to assume it's false and prove that. A discovery agent that debates itself self-censors [Anthropic-Yan](https://www.youtube.com/watch?v=imFedndyXYQ) (2026-07)
- **Treat the PR as hostile input to its reviewer**: vulnerable code wrapped in an innocent commit message fooled an autonomous review agent in 88% of attempts versus 35% for humans; retain human checkpoints for security-sensitive changes [Arize-Voss](https://www.youtube.com/watch?v=_mi3alkqy4s) (2026-09)
- **Agents fabricate rather than report tool failure**: a blocked or empty fetch becomes "I searched the web", and a failed fetch silently falls back to stale training data. Verify tool *results*; treat agent citations as unverified until fetched [Bright Data](https://www.youtube.com/watch?v=btxGmN8RvNU) (2026-06) [Wisedocs-Linkov](https://www.youtube.com/watch?v=7vn4WpqNpck) (2026-08)
- **Agents lie about doing work** (touched a sentinel file claiming tests ran) — require cryptographic proof: SHA-256 the actual test output into the marker file. A deterministic verify step should read the run's trace history to confirm it happened [WorkOS](https://www.youtube.com/watch?v=vy7o1g2iHY8) [IBM](https://www.youtube.com/watch?v=C_GG5g38vLU) (2026-05)
- **One prompt line can disable self-verification**: SWE-Bench Pro says tests are handled; even GPT-5.5 and Opus 4.8 then stop verifying. Audit prompts for accidental suppression of wanted behavior [DeepSWE](https://www.youtube.com/watch?v=Yk87oUPVaxU) (2026-07)
- Agents readily write shallow API tests; use them instead to BUILD fuzz harnesses that drive malformed/adversarial inputs, while humans enumerate meaningful conditions. Dioxus spent one day implementing a plugin, then two weeks on test cases and real devices [Dioxus-Kelley](https://www.youtube.com/watch?v=H7vFrcNWXzs) (2026-09)
- **Agents edit or delete the TEST to make it pass** — never let the agent modify a test; run a fast suite (~300ms) before AND after every change; fix red, because expected values ARE the spec [Kent Beck](https://newsletter.pragmaticengineer.com/p/tdd-ai-agents-and-coding-with-kent) [Playwright](https://www.youtube.com/watch?v=FWEInOtngmM) (2026-06)
- ...so make the ORDER explicit: write the failing test first, or require evidence it fails without the patch. Code-then-test fits the test to the code; test-then-code fits code to criteria [Figma-Blum](https://www.youtube.com/watch?v=5Bn0xro2ol8) [Pocock](https://newsletter.pragmaticengineer.com/p/ai-skills-with-matt-pocock) (2026-09)
- **Verification chain for an agent-authored perf rewrite**: unit + integration tests, THEN a canary — old and new taking the same traffic ~10 min — reading CPU, latency, error rate. "The profiler gives the estimate, the canary ground truth" [Netflix-Shah](https://www.youtube.com/watch?v=CgsWxRUY5Eo) (2026-07)

## Enforcement loop — pin to the action the agent must take
- The harness IS the enforcement loop: git hooks, CI and linters run identically locally and in CI, so skipping local checks gets caught downstream. **Deterministic instructions > prompt-nagging AT SCALE**: "PLEASE run tests" in screaming-caps AGENTS.md is a smell [SafeIntelligence](https://www.youtube.com/watch?v=504PvfXou5Y) (2026-06) [Stripe](https://www.youtube.com/watch?v=_xQnSNlBP_w) (2026-05)
- **Encode org policy at BOTH ends of the loop**: prevent forbidden actions with policy-as-code, then reactively check output; agents use the same enforced path as humans, never a skippable skill [Wayfair-Eubanks](https://podcasters.spotify.com/pod/show/mlops/episodes/How-Predictive-Analytics-Stops-Budget-Overruns-Before-They-Happen-e3nk2h1) (2026-08) [Barney](https://podcasters.spotify.com/pod/show/mlops/episodes/The-Caveman-Prompting-Challenge-e3pmsjk) (2026-10)
- **Session-END is the other attachment point**: a Stop hook runs a deterministic check suite when the agent finishes and feeds failures back — the agent doesn't declare done, with a judge tier only for what can't be checked deterministically [Checkout.com-Sheikh](https://www.youtube.com/watch?v=MpZzWMdmQCE) (2026-07)
- ...**make the check ASYNC so the stop hook stays cheap**: a write-tool hook runs the scanner in background, appending only NEW findings to a temp file; the Stop hook reads it, then starts a fix-and-validate loop. Latency hidden, context unbloated [Snyk-Tanzer](https://www.youtube.com/watch?v=cgimkNGNjvU) (2026-07)
- **Prevent whole bug classes by construction** instead of detecting instances: enforce architecture via module-import rules — a BDD suite forbidden from importing DB-accessing modules, templates forbidden from DB access, making N+1 queries structurally impossible [SafeIntelligence](https://www.youtube.com/watch?v=504PvfXou5Y) (2026-06)

## Guardrails & limits
- **Under-privileged credentials trigger credential-hunting**: give an agent a token too weak for its goal and it goal-seeks the filesystem for stronger ones. RL makes models *more* goal-seeking, not safer — alignment comes from infrastructure. Never keep secrets as files [LoopsDebate](https://www.youtube.com/watch?v=c35YoMdnI78) [Huntley+Keycard-WF26](https://www.youtube.com/watch?v=I2cbIws9j10) (2026-07)
- ...**the mirror case is worse**: an OVER-privileged token found lying around got a production database AND its backups deleted — the agent wasn't malicious, it was resolving what it read as a credential mismatch, and nothing stopped it [Snyk-Tanzer](https://www.youtube.com/watch?v=cgimkNGNjvU) (2026-07)
- **Steer vs ask, and "ask" is expiring**: *steer* = policy rewrites the action with no human (redact secrets pre-execution); *ask* = prompt the user. Background and overnight agents can't be asked, so pre-tool hooks must steer [Snyk-Tanzer](https://www.youtube.com/watch?v=cgimkNGNjvU) (2026-07)
- **Composable hard caps at the harness level**: max iterations (kill run), max messages (compact), max tool calls, retries, execution time, DIFF SIZE, read-only mode, no file deletion. Throttle by reading OpenTelemetry traces back into the loop every ~10 calls [IBM](https://www.youtube.com/watch?v=C_GG5g38vLU) [PwC](https://podcasters.spotify.com/pod/show/mlops/episodes/Autonomous-Agents-at-Work-From-OpenClaw-Hype-to-Enterprise-Reality-e3jj7u3) [Cerebras-Chieng](https://www.youtube.com/watch?v=TeGsFFNqRLA) (2026-05)
- **Confidence gate with a PRIVATE escalation channel**: an agent watching Slack answers only when confident, and when unsure DMs a human — so the public channel sees only vetted answers; uncertainty costs one glance, not a visible wrong reply [Resolve-Smith](https://www.youtube.com/watch?v=vSx5IULvBns) (2026-08)
- **Grant autonomy as an earned spectrum**: shadow (no outcome effect) → advisory (proposes, human approves) → gated action → autonomy, each earned on outcome evidence, reversible on regression. Classify by reversibility; gating = risk × blast radius, per ACTION [PwC](https://podcasters.spotify.com/pod/show/mlops/episodes/Autonomous-Agents-at-Work-From-OpenClaw-Hype-to-Enterprise-Reality-e3jj7u3) [Keys to my life](https://www.youtube.com/watch?v=sJ2jc7leKBk) (2026-05) [Accenture-GroganWang](https://www.youtube.com/watch?v=AGkzpxMdPn8) [Amazon-AGI-Mishra](https://www.youtube.com/watch?v=Cc0_nyxROBA) (2026-07)
- **80/20 hybrid loop-breakers**: ~80% open research on a high-reasoning model, ~20% hard-gated deterministic steps (validation, summarization, critic) on cheap non-reasoning models; cap research with use-last-result counters (4–5 iterations) or ~5-min timeouts — degrade to the last decision [Qodo](https://www.youtube.com/watch?v=EcqMYoIV57A) (2026-06) [BuzzHPC](https://podcasters.spotify.com/pod/show/mlops/episodes/Architecting-Modern-AI-Systems-Platforms--Agents--and-Integration-e3k0qlu) (2026-05)
- **Container ≠ agent platform**: a container knows one session and has no isolation across stateful sessions → an auto-accept agent pushed company source to personal GitHub, secrets commingled. Dev boxes (64–128GB, pre-warmed, ~10s spin-up) beat lightweight sandboxes [Cognition](https://www.youtube.com/watch?v=_xQnSNlBP_w) [Stripe](https://www.youtube.com/watch?v=_xQnSNlBP_w) (2026-05)

## Transparency, control & reversibility
- Transparent execution (live todo list, visible context and skills in use, tool-call inputs AND outputs) lets the user intervene mid-run before wasted steps compound. Multi-granularity reversibility (per-line, per-file, conversation-checkpoint rollback) bounds mistakes, making users bolder [Flinn](https://www.youtube.com/watch?v=7CrPrHgoEYk) (2026-05)
- Stay-in-the-loop devices for long runs: **implementation notes** — the agent logs every unknown it hits and why it chose what it did, so you audit deviations instead of diffing blind; and an **exit quiz** before merge [Fable-field-guide](https://www.youtube.com/watch?v=9fubhllmsBU) (2026-07)
- ...at fan-out scale reading trajectories stops being viable — 20–30 sub-agents fire per run. Read the end-of-run DECISION summary end to end instead, and prompt for one when the harness didn't emit it [Osmani-PE](https://newsletter.pragmaticengineer.com/p/from-chrome-devtools-to-ai-engineering) (2026-08)
- ...with the guard that makes that honest: a decision summary is GENERATED, not recorded, so it can confabulate — most likely on runs that exhausted the context window. Check it against the durable log (§ Event-sourced design) [Osmani-PE](https://newsletter.pragmaticengineer.com/p/from-chrome-devtools-to-ai-engineering) (2026-08)

## Multi-agent orchestration
- **Yardstick for any multi-agent design**: the ideal is ONE agent, one window, all the world's information — multi-agent exists only because privacy forbids that. Score a design by how closely it approximates it [Town-Greze](https://www.youtube.com/watch?v=REascnFlq_8) (2026-09)
- ...paired end-game test: does it need FEWER humans over time, and does it improve as models improve? Sharing inside a trust boundary and hand-built privacy tools fail both — a human thought about each one [Town-Greze](https://www.youtube.com/watch?v=REascnFlq_8) (2026-09)
- **Run features SERIALLY** (one worker/validator at a time), parallelizing only READ-ONLY ops. Naive parallelism fails for SWE: agents step on each other's changes and make inconsistent architectural decisions. Consolidate judgment into one agent; sub-agents return results, never judgment [Factory-Alvoeiro](https://www.youtube.com/watch?v=ow1we5PzK-o) (2026-05) [ZS](https://www.youtube.com/watch?v=u6jJcIFDLE4) (2026-07)
- For open-ended knowledge work, a main agent decomposes aspect queries and parallel READ-ONLY search agents return memos; on MTabQA this cut the error gap versus humans about 40% [Mixedbread-Clavié](https://www.youtube.com/watch?v=O84lhGc1OOI) (2026-09)
- **Live disagreement on where orchestration logic lives.** Factory keeps ~all of it in prompts + skills per mission (~700 lines; 4 sentences change execution strategy). WorkOS moved it INTO deterministic code. Decider: how much the orchestration changes per run [Factory-Alvoeiro](https://www.youtube.com/watch?v=ow1we5PzK-o) [WorkOS](https://www.youtube.com/watch?v=vy7o1g2iHY8) (2026-05)
- **Tokens are not fungible — give them jobs**: at a FIXED budget, allocating tokens to non-executor roles beats pure execution — *advise*, *grade*, *dream* (reflector writes to memory). Financial-analyst bench, same 600k budget: execute 0.76 vs advise 0.89 [Anthropic-WF26](https://www.youtube.com/watch?v=I2cbIws9j10) (2026-07)
- **Route by task, not general intelligence** — a prompt-and-loop often FAILS on narrow reliability even when it impresses in chat. Task-*type* routing is fragile once agentic: complexity shifts mid-session (explore → implement → debug); keep a frontier agent *watching* [ElevenLabs](https://podcasters.spotify.com/pod/show/mlops/episodes/Voice-Agent-Use-Cases-e3ileg6) (2026-05) [Cognition/Yan](https://www.youtube.com/watch?v=QHBjufYK8TA) (2026-08)
- **Route subproblems, not whole tasks**: expose large context as files, extract subcontexts, then match each subtask to model and hardware by modality/complexity. Vendor benchmark reported 3–12× speed/cost gains; treat the magnitude as unverified [Callosum](https://www.youtube.com/watch?v=WRBNDpUhsJQ) (2026-05)
- **Sidekick beats spawning sub-agents** for a reused delegate: ONE long-lived side agent holding a running context means the main agent never re-supplies context, staying in KV cache (~10× cheaper on cached tokens). It returns *file references*, not content dumps [Cognition/Yan](https://www.youtube.com/watch?v=QHBjufYK8TA) (2026-08)
- **Org-chart hierarchy as real entity types** (CEO/VP/manager/worker): each layer its own agent with scoped context and an approval boundary; the human reviews only the top. A flat pile of >4–5 agents makes the human the scheduler [KRAFTON-fleet](https://www.youtube.com/watch?v=4kYl2_mqmnQ) (2026-07)
- **Stripe "Minion" loop** (prompt→PR, ~65% merge, zero edits): `analyzer` localizes the area → one coding turn → lints/tests/typecheck → an LLM judge sees the diff plus the ORIGINAL prompt, NOT the agent's excuses → a `diagnostic` note feeds back [Stripe](https://www.youtube.com/watch?v=_xQnSNlBP_w) (2026-05)
- **Best-of-N agent runs are "map without reduce"**: fanning out 100 agents is easy; the missing primitive is REDUCE (test-pass count is one). Exception where reduce is free — TASTE tasks (UI, design): generate 15 variants and eyeball them [Sazabi](https://podcasters.spotify.com/pod/show/mlops/episodes/Logs-Are-All-You-Need-Rethinking-Observability-with-AI-Agents-e3jthog) (2026-06) [Cerebras-Chieng](https://www.youtube.com/watch?v=TeGsFFNqRLA) (2026-05)
- ...**a deterministic verifier plus a shared leaderboard IS that reduce**, and it compounds across runs: agents reading and refining each other's ranked submissions took the 11-dimension kissing number 593→604 in ~48h, beating AlphaEvolve. No single agent solved it [Zou-Arena](https://www.youtube.com/watch?v=mMNkdYnIVC4) (2026-08)
- ...persona split as the diversity source: separate agents primed on profiling, on memory consumption and on precision, competing on one leaderboard, produced >2× speedups on kernels now in production at Together AI [Zou-Arena](https://www.youtube.com/watch?v=mMNkdYnIVC4) (2026-08)
- **Cross-repo meta-harness**: agents are repo-bound, so one logical change spanning N repos costs ~N re-explanations. Fix = an agent-agnostic layer extracting metadata from all reachable repos into ONE dependency graph, selecting by INTENT ("every repo depending on lib vX") [Nx-Savkin](https://www.youtube.com/watch?v=jVjt-2g8NMY) (2026-06)
- ...**live disagreement**; the blunt alternative, chosen first-hand: 10 repos → one monorepo, on the finding that NAVIGATION was never the problem — testing, verification and deployment are. Decider: comprehension bottleneck → meta-harness; verify/deploy bottleneck → monorepo [Wisedocs-Linkov](https://www.youtube.com/watch?v=7vn4WpqNpck) (2026-08)

## Plan-heavy vs review-heavy — optimizing for human time
- **Plan the stack BEFORE code** (30 min upfront reliably saves hours of review): product review → system architecture (component contracts, data models) → **program design** (types, method signatures, call stacks — the most-skipped step) → vertical slices with checkpoints [HumanLayer/Horthy](https://www.youtube.com/watch?v=htM02KMNZnk) (2026-07)
- Scope alignment by reversibility: tiny/easy-to-undo change → review after; complex one-session change → interrogate first; multi-session project → persistent map/spec plus one bounded ticket per session [Pocock](https://newsletter.pragmaticengineer.com/p/ai-skills-with-matt-pocock) (2026-09)
- Models write **horizontal** plans (DB → services → API → front end): nothing is testable until the end, and you review 2000 lines at once. Slice vertically — mock endpoint, front end, real data, migration — five verifiable diffs [Horthy-CtxEng](https://newsletter.pragmaticengineer.com/p/context-engineering-with-dex-horthy) (2026-07)
- **Size each slice as a PR you'd review in ONE SITTING** ("if I need a coffee first, it's too big"), and give every phase its own validation gate, so phase 5 never stacks on unvalidated phase 1 [Figma-Blum](https://www.youtube.com/watch?v=5Bn0xro2ol8) (2026-08)
- ...and open the plan with a bold **why / executive summary** the agent is told not to edit — an anchor against drift on a long run [Figma-Blum](https://www.youtube.com/watch?v=5Bn0xro2ol8) (2026-08)
- Agent coding displaces effort into planning and reviewing (~20 min back per 30 min coding), not free time — optimize for accuracy per HUMAN time, not wall-clock. Matrix: frontend → stay in-loop; backend → plan-heavy/TDD; refactor/migration → fully plan-heavy [Plan and Review](https://www.youtube.com/watch?v=W76woOYHlvY) (2026-05)

## Loop engineering — in-the-loop → out-of-the-loop
- **Loops as control theory, not bash**: set point (desired end state for one property), sensor, measured error, controller (one incremental change), actuator, re-measure. Precedents — thermostats, Kubernetes autoscaling, IaC desired-vs-current. Incrementality is what prevents 40k-line PRs [HumanLayer-Mistele](https://www.youtube.com/watch?v=xIt_mTQp6mY) (2026-07)
- **Stop the bleeding before migrating**: one full scan on main, violations sorted deterministically and committed, then fail any PR adding new ones. Build "golden patterns" by hand before setting the actuator loose, because agents are pattern replicators [HumanLayer-Mistele](https://www.youtube.com/watch?v=xIt_mTQp6mY) (2026-07)
- **Flow control beats throughput**: label PRs per loop, exit if one is still open — no human reviewed the last output, so producing more is waste. An `/iterate` PR comment re-triggers the loop, feedback appended to a version-controlled file [HumanLayer-Mistele](https://www.youtube.com/watch?v=xIt_mTQp6mY) (2026-07)
- **"Loop engineering"**: author the loops that prompt the agent, so your job moves to issue-writing on one end and code review on the other. Pull the human out one stage at a time but keep the final merge gate [Warp](https://www.youtube.com/watch?v=gi0Lx6c84VE) (2026-06) [Osmani-PE](https://newsletter.pragmaticengineer.com/p/from-chrome-devtools-to-ai-engineering) (2026-08)
- **Feed agents, don't babysit them**: state the self-validation criteria up front so it returns only when the work compiles, passes tests and hits coverage — then move that into the steering file so it happens every run [AWS-Liguori](https://www.youtube.com/watch?v=pqlWNihgdjI) (2026-08)
- ...make review TARGETED rather than uniform by having the loop flag when a change touches a critical part of the system. A loop building everything with no blast-radius guardrail is the named recipe for disaster [Osmani-PE](https://newsletter.pragmaticengineer.com/p/from-chrome-devtools-to-ai-engineering) (2026-08)
- Slow loops carry the most practitioner confidence: a nightly cron fixing one linter finding, grown along two axes — more feedback mechanisms (including hand-written "here's good, here's bad" rules where no deterministic tooling exists), then more scope per run [Horthy-CtxEng](https://newsletter.pragmaticengineer.com/p/context-engineering-with-dex-horthy) (2026-07)
- Cost objection from a practitioner running loops: non-deterministic verification adds non-determinism rather than removing it (compounding math in evals.md § LLM judges). Where loops demonstrably pay: security scanning on PRs at ~$5/PR, and domains with existing test suites [LoopsDebate](https://www.youtube.com/watch?v=c35YoMdnI78) (2026-07)
- Two-stage chain beats one agent: automation A turns an under-specified issue into a spec doc you merge as a paper trail, and automation B implements it. Each loop is only as good as its acceptance criteria [Warp](https://www.youtube.com/watch?v=gi0Lx6c84VE) (2026-06)
- Two things they learned: adoption came from LATENCY, not quality (~20% of scoping time saved); and **the ENDS of a pipeline automate first** — context-gathering works, spec→code largely one-shots, and the scope→spec middle is the hard part [Ramp-Mehr](https://www.youtube.com/watch?v=ITMXwI6QL6A) (2026-07)
- **Never let the loop close or mark-done its own work** — stay the final verification gate. If the builder grades its OWN work you didn't remove review, you HID it; capability drift only moves WHERE proof belongs, never WHETHER [Ralph-Parsons](https://www.youtube.com/watch?v=2TLXsxkz0zI) (2026-05) [Volkov](https://www.youtube.com/watch?v=ZpK5PWX2YRM) (2026-07)

### Monitoring-triggered loops (post-launch)
- **The "missing layer" is post-launch, triggered by LOG MONITORING**: an agent runs every 15–60 min over a ~1h window with codebase access, diagnoses stuck or "successful-but-wrong" users, opens a PR — gated by a SEPARATE review agent, FRESH context [Wandero](https://www.youtube.com/watch?v=kZsf_Sfm7RU) (2026-07)
- Funnel production exceptions deterministically before involving an agent: require full stacks, fingerprint and rank by affected users, assign an owner, then open a diagnosis plus proposed-fix PR [VS Code-Kirschner](https://www.youtube.com/watch?v=I2LL_wd89-A) (2026-10)
- **Change-triggered variant: a check plan PER RELEASE, not fixed CI checks.** The agent reads what changed, infers which telemetry is causally downstream and picks the cadence. Its real gain is what CI never sees: feature flags and infra edits [Resolve-Smith](https://www.youtube.com/watch?v=vSx5IULvBns) (2026-08)

## Agent-rate development — CI in the loop, merge queues
- **The PR breaks as the unit of work at agent scale**: agents emit N PRs across N repos with thousands of short-lived branches. Validation moves OUT of a post-PR CI phase and INTO the agent's inner loop [Namespace](https://www.youtube.com/watch?v=VktrqzQgytY) (2026-05)
- OpenAI moved review to PR creation: “finalize code” skills self-heal before CI. At ~1,200 tok/s versus ~40–60, running tests, linters and browser QA every step becomes cheap [OpenAI-Liu-MLOps](https://podcasters.spotify.com/pod/show/mlops/episodes/How-To-Delegate-To-An-Agent-Like-You-Would-An-Employee-e3nglg8) (2026-08) [Cerebras-Chieng](https://www.youtube.com/watch?v=TeGsFFNqRLA) (2026-05)
- **De-risking displaces speed as the pipeline priority**: with an agent driving there's no context-switch cost waiting on a build. Shipped as a standing loop with a checklist — every 30 min: rebased on main, review comments addressed, CI green [CI/CD Erez](https://newsletter.pragmaticengineer.com/p/cicd-with-robert-erez) (2026-06) [OpenAI-Liu-MLOps](https://podcasters.spotify.com/pod/show/mlops/episodes/How-To-Delegate-To-An-Agent-Like-You-Would-An-Employee-e3nglg8) (2026-08)
- **"Agent readiness" = how many DETERMINISTIC validation loops your codebase already has** (linters, type checkers, security scans, e2e tests) — output quality tracks how much you can validate, so **where you can't build a validator is where autonomy stops** [Factory-Reyes](https://www.youtube.com/watch?v=wpOA-UXynoM) (2026-07)
- ...the evidence: their legal workflow is ~100% autonomous while their own harness isn't, lacking a check on visual bugs. Same claim from the other end — coding crossed the trust threshold FIRST purely because code runs and tests [Factory-Reyes](https://www.youtube.com/watch?v=wpOA-UXynoM) [Amazon-AGI-Barth](https://www.youtube.com/watch?v=2JX6JYyQG4Y) (2026-07)
- Sequencing caveat: only ~30–40% of agent-readiness gaps are click-to-fix; the rest need workflow change, and humans resist the nitpickiness of the new checks. Metric they run is "autonomy ratio" — AI vs human actions before an interruption [Factory-Reyes](https://www.youtube.com/watch?v=wpOA-UXynoM) (2026-07)
- **"Self-validation == an ephemeral environment"**: every self-check loop is really spin-up env → agent pokes → tear down. Granola turned a one-instance Electron app into a web shell so CI emits a per-PR preview link the agent tests against [CI/CD Erez](https://newsletter.pragmaticengineer.com/p/cicd-with-robert-erez) [Granola](https://www.youtube.com/watch?v=ON5LIT0M4do) (2026-05)
- **A PARTIAL verification engine is worse than none.** At ~50% Excel coverage, the agent writes a formula correct in the real tool, the engine errors, and it "fixes" working code. Build the sensor to fidelity *before* closing the loop [Witan-Campos](https://www.youtube.com/watch?v=HEFSExa0xl0) (2026-07)

## Dynamic workflows — a bespoke harness per task
- **Six portable harness patterns**: classify-and-act; fan-out-and-synthesize (isolated contexts so biases don't cross-contaminate); worker+critic against a rubric (cures self-preferential bias); generate-and-filter; tournament (pairwise beats absolute scoring); loop-until-done, gated on "any new findings?" [Prompt Engineering](https://www.youtube.com/watch?v=l5rae4LMKBc) (2026-06)

- **Golden-session → reusable workflow → then CRYSTALLIZE it**: an agent can compile a repeated request into deterministic code; WorkOS generates JS widgets whose refreshes bypass the model. Keep reasoning only for changes [OpenProse](https://www.youtube.com/watch?v=3hXJI2q0Jz8) [WorkOS-Studio](https://www.youtube.com/watch?v=iUWwcG-C8OU) (2026-06)
- A factory should consume workflow events, not merely emit PRs: ticket completion releases dependency-blocked work, then the agent rechecks the plan for newly discovered missing tickets [WorkOS-Cooke](https://www.youtube.com/watch?v=HvboD89DyQ8) (2026-09)
- Compile repeated LLM work into scripts: the agent inspects one page, writes a deterministic parser, then the script runs (~100 tokens/run vs ~10k; ~62% saving). Pair with a self-healing check that patches the scraper on missing fields [Bright Data](https://www.youtube.com/watch?v=zTZ0qunQXnM) (2026-06)
- ...but **don't cost-optimize while experimenting**: run the expensive agent on the same problem ~100×, watch its solutions converge, and only THEN compile that step into a one-shot call — premature avoidance of agent calls was PostHog's biggest mistake [PostHog](https://www.youtube.com/watch?v=zMiSRliEzv4) (2026-06)
- **Live disagreement, from a negative result**: Pinterest moved a shipped diagnostics agent to explicit LangGraph workflows for determinism and found it BRITTLE versus reasoning-and-acting. Reconciles as: compile the known verification steps, keep the investigation path reasoning-based [Pinterest-Profirovic](https://www.youtube.com/watch?v=0RNNfxpdbQk) (2026-07)
- Split production automation by task variability: deterministic nightly workflow scanned papers and opened issues; autonomous CLI+skill+sandbox handled variable replies, one container per issue, fanned out in batch [Hugging Face](https://www.youtube.com/watch?v=FLUoowDJg4I) (2026-08)

## Running LLM-generated code — sandboxes
- **"Seven stages of sandboxing"**: teams try fork/exec → containers/seccomp → gVisor → V8 and all end at microVMs — hardware virtualization is the only boundary surviving guest root. Start there (Firecracker / Cloud Hypervisor / crosvm) [OpenAI-Bhardwaj](https://www.youtube.com/watch?v=OqM67QG_Ikk) (2026-07)
- Keep secrets outside the agent guest and substitute scoped placeholders at network egress; mount related repositories read-only when they are context, not mutation targets [Docker-Christmas](https://www.youtube.com/watch?v=OE_lLNCNfQo) (2026-10)
- Decompose cross-system work at trust boundaries: GitHub-read sandbox produces a summary, separate Notion-only sandbox writes it; passing the artifact prevents one process from accumulating both credentials [Docker](https://www.youtube.com/watch?v=zaGyGgLW3SM) (2026-08)
- Syscall-allowlist (seccomp) filters fight GENERAL agents: you can't enumerate needed syscalls up front and blocked calls make a terrible feedback loop — isolate the environment rather than over-restricting. "System tricks can cover performance issues; they cannot hide security breaches" [OpenAI-Bhardwaj](https://www.youtube.com/watch?v=OqM67QG_Ikk) (2026-07)
- **Inverted sandbox design**: start from a zero-capability JS isolate (no fetch, no filesystem, no env vars), granting capabilities outward, not locking a VM down afterwards. Full-stack version: generated UI in a null-origin iframe, server code in a no-egress worker [Cloudflare](https://www.youtube.com/watch?v=SKDJo2CopRs) (2026-06) [Varda/Cloudflare](https://www.youtube.com/watch?v=RmS5s6Wbin4) (2026-08)

## Self-evolving harnesses, trajectory stores & retro
- **Route failures to a CLASS of fix so correction becomes code, not opinion**: wrong workflow → classifier eval; wrong write → write gate; wrong assumption → review. "Please be careful is not a guardrail" (100k+ corrections in 9 months) [Maersk-Buykin](https://www.youtube.com/watch?v=dQ-_i1tZiws) (2026-08)
- **Meta-harness optimization needs a measurement surface first**, which makes arbitrary design choices ("is a strategist+worker split arbitrary?") answerable — build 10–20 careful environments, then let an LLM read traces and edit the harness. The durable value is ENVIRONMENT-building [MorganStanley-AlphaLab](https://www.youtube.com/watch?v=kiqubc5b5Yo) (2026-07)
- **Self-fixing agent pattern**: observability skills pull production traces into FILES in the repo, not an API call — coding harnesses work well with files. Deliberately-scoped skills (one session's traces, not generic full-data access) determine whether it finds the issue [Arize-Lopatecki](https://www.youtube.com/watch?v=9HbzAWnKbo4) (2026-07)
- Same pattern for performance: a weekly autonomous perf-audit workflow with MCP access to production traces posts scored high-ROI fixes to Slack. Map production metrics to function/file level, not service level, because coding agents reason at that granularity [HUD-Walter](https://www.youtube.com/watch?v=JJGbw4ggaFs) (2026-07)
- **End every agent invocation with a short retrospective** — what went well, what went wrong, what tools were missing, what context would help. Aggregating across runs makes the system debuggable at scale; recurring classes were infrastructure and repo complexity [Form3](https://www.youtube.com/watch?v=LqLoYksJ6do) (2026-07) [Osmani-PE](https://newsletter.pragmaticengineer.com/p/from-chrome-devtools-to-ai-engineering) (2026-08)
- **"Agentic map-reduce" over your own history**: map cheaply over past sessions to extract every place you corrected the agent, reduce with a stronger model into recurring-failure categories, then feed those into eval tasks or a skill [Harbor](https://www.youtube.com/watch?v=jRCpXUjz4CI) (2026-07)
- ...cheaper trigger, in the moment: when you catch yourself telling the agent something you can SEE and it can't ("the button is a bit to the left"), that's the affordance to build [Poolside-Lajili](https://www.youtube.com/watch?v=iRcX54EO5g8) (2026-07)
- **Past a certain length you cannot read a trace WITH an agent** — treat it as an external object to query. Write the classifier as CODE, run it in a sandbox: cheap code for map, smart model for reduce [LangChain-Trivedy](https://www.youtube.com/watch?v=CvRngaQZQ3Y) [Raindrop-Hylak](https://www.youtube.com/watch?v=jHMiYtjoJfA) (2026-08)

## Org-scale rollout & adoption
- **Org-level (multiplayer) harness as the next shape**: one harness the whole org shares, with its own identity and credentials not tied to a user, and org-level rather than local context. A team agent lands ~65% of one team's PRs [Anthropic-Martin](https://www.youtube.com/watch?v=9QebvrrY3KY) [Anthropic-CC](https://www.youtube.com/watch?v=uU5Gv2h8-9g) (2026-07)
- **Live disagreement on agent identity, decided by work ownership**: for a per-user fleet run the agent as the USER — paired machine identity drifts out of permission sync, doubles licences, and breaks systems rejecting two identities on one mailbox [TwoSigma-Fang](https://www.youtube.com/watch?v=wCIYViPd4SU) (2026-09)
- ...cheap because the primitive already exists: the per-user Kubernetes namespace you already run notebooks and batch jobs in, with a sidecar mounting the identity into the pod [TwoSigma-Fang](https://www.youtube.com/watch?v=wCIYViPd4SU) (2026-09)
- **Address ONE session from every surface, rather than a bot per surface**: a Slack bot alone just moves the agent from trapped-on-a-laptop to trapped-in-Slack. One session across Slack, app and GitHub means nobody re-supplies context at a handoff [Superconductor-Singh](https://www.youtube.com/watch?v=OL7kfezynJM) (2026-08)
- **Treat it as leadership's problem, not the IC's**: the highest-leverage fixes need buy-in no individual can get. Failure mode of "figure it out yourself" — adopters ship 10 PRs/day, non-adopters 1–2 AND inherit the review burden [Amazon-AGI-Khandelwal](https://www.youtube.com/watch?v=aeTb5BdmTTc) (2026-08)
- **Slow down to speed up**: nearly every team in a 50-team Amazon pilot saw productivity DROP first while they rewrote tool error messages, built mocks and restructured code for navigability. Expecting instant gains is the org anti-pattern [AWS-Liguori](https://www.youtube.com/watch?v=pqlWNihgdjI) (2026-08)
- ...and going broad too fast is the other: 50 pilot teams first, then 2,000, because you can't scale practices you haven't found yet [AWS-Liguori](https://www.youtube.com/watch?v=pqlWNihgdjI) (2026-08)
- **Live disagreement on standardizing the agent platform**: one platform compounds tooling and kills per-task "model anxiety"; against it, one team churned 5 platforms in 12 months, each stranding context. Decider — standardize the platform, keep the SKILL layer portable [Intercom](https://www.youtube.com/watch?v=4_VQBbs2iQA) (2026-05) [Atlan/Sankar](https://www.youtube.com/watch?v=8G_1-3IO4ZQ) (2026-07)
- ...a third position splits the object: centralize the ARTIFACTS (skills, review rules, governance), leave each person's LOOP alone — centralizing everyone on one workflow hits diminishing returns [Figma-Blum](https://www.youtube.com/watch?v=5Bn0xro2ol8) (2026-08) [Uber-uReview](https://www.youtube.com/watch?v=EL123UNokkI) (2026-08) [Twilio-Manuja](https://www.youtube.com/watch?v=zrZ1amZBSPw) (2026-08)
